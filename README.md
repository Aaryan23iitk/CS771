## Assignments

### Minor Assignment 1 — C-SVM & SDCM Solver
Debugged a broken C-SVM implementation on an Arbiter PUF dataset. Fixed errors in the SDCM algorithm and analysed primal-dual convergence. Experimented with hyperparameters like C, coordinate generators, initialization, and training size.

### Minor Assignment 2 — Gaussian Mixture Models on MNIST
Derived training and inference equations for a GMM-based generative multi-class classifier. Implemented it on MNIST, plotted accuracy vs number of components K, and extended it to handle missing pixel reconstruction.

### Major Assignment — Kernel Regression + XOR Arbiter PUF Inversion
Designed a custom kernel K̃ to convert a semi-parametric regression problem into kernel ridge regression, tuned polynomial kernel hyperparameters (degree d, coefficient c), and reported R² scores. Also inverted a 1089-dimensional XOR Arbiter PUF linear model to recover 256 non-negative physical delays using Kronecker product decomposition.
